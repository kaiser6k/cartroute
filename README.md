# CartRoute

A route planner prototype for golf carts and low-speed vehicles (LSVs) in Florida. Enter your cart's top speed and equipment (lights, turn signals, seat belts, mirrors, windshield), and it plans routes on roads your cart can likely use, with a place finder that checks whether each place is reachable.

**Important:** the road rules are simplified. Florida golf carts may only use roads designated by the local government, and that data is not in the map, so some routes are assumptions. Always check local ordinances before driving.

Open `index.html` in a browser or host it as a static site. Profile settings are stored in your browser only.

Map data comes from OpenStreetMap contributors (https://www.openstreetmap.org/copyright).
